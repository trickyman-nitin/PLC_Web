Run a motor starter from your phone. This is a hands-on automation demo. A Siemens S7 PLC runs the star-delta logic, a small Node.js server talks to it over the S7 protocol, and a mobile-friendly page shows the pilot lamps and the changeover timer live. Press START, watch the star lamp, and see it switch to delta after 10 seconds. It’s built for students learning PLC programming, industrial communication and web HMIs together.
